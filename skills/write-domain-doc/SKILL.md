# 域知识文件生成(问答式四要素)

## 工作流

1. 问用户:这个域的**不变量**——什么被破坏就是事故?(至少 2 条)
2. 问用户:改这个域时,**哪些地方必须格外小心**?改了要连带验证什么?
3. 问用户:改完后,**必验的场景**是什么?(写成可执行判据)
4. 问用户:这个域**踩过的坑**——当时现象是什么、根因是什么?(提炼为反例)

## 生成规范

- 判据必须可执行(能变成验证动作);用户说出「注意 XX」时追问「怎么算注意到了?」
- 反例标注来源(哪次事故)
- 生成后让用户通读一遍确认,再写入 `.ai/agents/<domain>.md`
- 一个域一个文件,文件名 = 域名(kebab-case)
